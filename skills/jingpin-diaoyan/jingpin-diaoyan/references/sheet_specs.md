# 竞品调研框架 Sheet 规范（通用版）

## Sheet 1: 竞争品牌定位

### 结构
- N列 × 关键词数行
- R3: 图例行「蓝海词 / 含品牌名 / 品牌+蓝海 / 普通词」
- R4+: 数据行，3组排列（每组5列：关键词/推荐理由/竞争指数/月搜索指数/市场出价）

### 颜色
| 条件 | 底色 | 颜色码 |
|:--|:--|:--:|
| 蓝海词（推荐理由含"蓝海"） | 浅蓝 | `D1E7FF` |
| 含品牌名 | 黄色 | `FFF3CD` |
| 品牌+蓝海 | 浅青 | `CFF4FC` |
| 普通词 | 无 | 白底 |

### 样式
- 字体：Arial 10号
- R3图例行：居中，9号Arial
- 边框：浅灰 D1D5DB 细线
- 品牌名列表需品类自定义

---

## Sheet 2: 小红书热搜产品

### 结构
- 9列 × 数据行（品牌分组）
- R1: 表头行（蓝底白字）

### 列字段（A~I）
| 列 | 字段名 | 说明 |
|:--|:--|:--|
| A | 关键词1（品牌名） | 品牌名+搜索指数，同品牌合并 |
| B | 搜索指数 | 品牌搜索指数 |
| C | 关键词2（产品名） | 具体产品名 |
| D | 搜索指数 | 产品搜索指数 |
| E | 淘宝链接 | 淘宝商品页/搜索页链接 |
| F | 产品图（商品主图） | 130×130嵌入图，**每个产品不同** |
| G | 价位 | 价格区间 |
| H | 属性选项 | 规格/香型/容量等 |
| I | 类型 | 品类分类 |

### 品牌行底色（8色循环）
1. `E0F5FF`（淡蓝） 2. `FFF3E0`（淡橙） 3. `F0FFF0`（淡绿） 4. `FFF0F0`（淡粉）
5. `F3E5F5`（淡紫） 6. `E8F5E9`（淡翠） 7. `FFF8E1`（淡米） 8. `F5F5F5`（淡灰）

### 样式
- 表头：深蓝底 `0F172A` + 白字10号Arial，带自动筛选
- 品牌名行：粗体
- 列宽：A=18 B=11 C=26 D=11 E=18 F=22 G=14 H=34 I=14

### 图片规则
- 130×130嵌入图
- 同一品牌不同产品必须用不同的淘宝商品主图
- 不同品牌尽量用不同图

## Sheet 3: 竞品产品对比

### 结构
- 28+行 × 品牌数列
- 数据从 **B列** 开始填（不是C列！）
- R1~R28/R29/R30 共28+参数，品类自适应

### 固定尾部（所有品类通用，在最后3行）
| 行 | 参数维度 | 说明 |
|:--:|:--|:--|
| 倒数第3 | 颜值评分 | ★★★★☆ 风格/颜值/设计感评分 |
| 倒数第2 | 综合推荐指数 | ★★★★☆ 综合性价比/口碑评分 |
| 最后 | 推荐理由 | 一句话总结，**行高=80** |

### 参数维度（香薰蜡烛示例）
| 行 | 参数维度 | 说明 |
|:--:|:--|:--|
| R1 | 商品链接/品牌官网 | 链接行 |
| R2 | 品牌 | 品牌名，**必须黄色底色** FFFFFF00 |
| R3 | 产品名 | 具体产品名 |
| R4 | 图片 | 100×100嵌入图，**R4行高=120** |
| R5 | 价位 | 价格区间 |
| R6 | 香型 | 花香/木香/果香 |
| R7 | 成分 | 大豆蜡/石蜡 |
| ... | ... | 品类自适应参数 |

### 颜色
| 区域 | 底色 | 字体 |
|:--|:--|:--|
| A列（参数名） | `FF6699CC` | 白字9号加粗左对齐 |
| R1链接行 | 白底 | 8号蓝 `2563EB` 下划线 |
| R2品牌行（B~J列） | `FFFFFF00` 黄色 | 黑字9号居中 |
| 数据行 | 白底 | 黑字9号居中 |

### 图片
- 100×100嵌入图
- **R4行高=120**（否则图片超出格子）
- 每个品牌列嵌入对应品牌的产品图

## 通用规范

### 颜色速查
| 用途 | 颜色码 |
|:--|:--|
| 表头深蓝底 | `0F172A` |
| 表头白字 | `FFFFFF` |
| 蓝海底 | `D1E7FF` |
| 品牌黄底 | `FFF3CD` |
| 品牌蓝海浅青 | `CFF4FC` |
| Sheet3 A列蓝底 | `FF6699CC` |
| 边框 | `D1D5DB` |
| 链接蓝 | `2563EB` |

### 字体规范
- 表头：Arial 10号白字
- 正文：微软雅黑9~10号
- A列参数名：微软雅黑9号加粗白字
- 链接：微软雅黑8~9号蓝字下划线
- 边框：D1D5DB浅灰细线
- 对齐：居中，自动换行
