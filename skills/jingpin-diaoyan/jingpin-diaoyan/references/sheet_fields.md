# Sheet字段说明

## Sheet1 竞争品牌定位字段

| 字段 | 说明 | 示例 |
|:--|:--|:--|
| 关键词 | SEM关键词 | diptyque香薰蜡烛 |
| 推荐理由 | 词性标注 | 品牌词(蓝海) |
| 竞争指数 | 竞争激烈度 | 0.52 |
| 月搜索指数 | 月搜索量 | 4569 |
| 市场出价 | CPC出价 | 1.86 |

### 分组逻辑
- 品牌词：关键词含品类品牌名
- 蓝海词：推荐理由含"蓝海"
- 品牌+蓝海：同时满足品牌+蓝海
- 普通词：其他

### 品牌名列表（品类自定义）
每个品类不同，需AI分析关键词后提取出现的品牌名。
