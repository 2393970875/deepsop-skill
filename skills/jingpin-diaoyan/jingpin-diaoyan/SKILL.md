# 竞品调研框架构建（通用版）

从CSV关键词数据和品类信息，构建完整竞品调研Excel（3个Sheet），含颜色标注、淘宝主图获取与嵌入、参数对比。

## 适用场景

- 给定CSV关键词数据（1000条）+ 品类名，需要做竞品调研框架
- 需要从淘宝商品页提取不同产品的商品主图并嵌入Excel
- Sheet2需要9列A-I框架，每行产品不同的淘宝主图
- Sheet3需要28参数×10品牌横向对比，含图含链接

## 前置要求

- CSV关键词数据（包含「关键词」「推荐理由」「竞争指数」「月搜索指数」「市场出价」等字段）
- Python环境（通过`uv`或`D:\anaconda\python.exe`管理）
- Python包：openpyxl, Pillow(PIL)
- 浏览器工具（用于从淘宝获取商品主图，需登录淘宝）

## 3个Sheet结构一览

| # | Sheet名 | 结构 | 维度 |
|:--|:--|:--|:--|
| 1 | 竞争品牌定位 | 3组排列×5列/组 + 颜色标注 | 1000条关键词→4分组 |
| 2 | 小红书热搜产品 | 9列A-I × 30产品行 + 8色循环 | 17品牌×30产品 |
| 3 | 竞品产品对比 | 28参数行 × B~K品牌列 | 10品牌×28参数 |

### Step 1：解析CSV & 分组
- 读取CSV（编码utf-8-sig）
- 分析每个关键词是否含品牌名 → 品牌词/非品牌词
- 分析推荐理由是否含"蓝海" → 蓝海词/普通词
- 分4组：品牌词 / 蓝海词 / 品牌+蓝海词 / 普通词
- 提取品牌名列表（需按搜索指数排序，取前15-20个品类相关品牌）

### Step 4：淘宝商品主图获取（已验证的浏览器+CDP方案）

这是整条链路中最关键的步骤。

**方案：浏览器evaluate + Python下载**

1. **打开淘宝搜索页**（首次用`browser open`，后续用`browser navigate`复用同一tab）
   ```
   https://s.taobao.com/search?q={品牌+产品名}
   ```

2. **用`browser act kind="evaluate"`提取图片URL**
   - 必须使用原始targetId（如`162FD3C4A0CEEC9BCEE3FBEC59689A73`），不是tabId（如`t24`）
   - 目标页面：淘宝搜索结果页

   **JavaScript提取代码：**
   ```javascript
   () => {
     const results = [];
     document.querySelectorAll('img').forEach(img => {
       let src = img.getAttribute('src') || img.getAttribute('data-src') || '';
       if (src && src.includes('alicdn') && (src.includes('.jpg') || src.includes('.jpeg')) && !src.includes('gif') && !src.includes('webp')) {
         const b = img.getBoundingClientRect();
         if (b.width > 50 && b.height > 50) {
           if (src.startsWith('//')) src = 'https:' + src;
           results.push(src);
         }
       }
     });
     return JSON.stringify([...new Set(results)].slice(0,5));
   }
   ```

3. **下载图片（必须带Referer头）：**
   ```python
   import urllib.request, io
   from PIL import Image
   url = "上面提取的URL"
   req = urllib.request.Request(url, headers={
       'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36',
       'Referer': 'https://www.taobao.com/'  # 必须带！
   })
   data = urllib.request.urlopen(req, timeout=10).read()
   img = Image.open(io.BytesIO(data)).convert('RGB')
   img.save(f"imgs/{product}.jpg", 'JPEG', quality=92)
   ```

4. **嵌入Excel：**
   ```python
   from openpyxl.drawing.image import Image as XlImage
   xl = XlImage(fpath)  # 必须用文件路径，不能用BytesIO
   xl.width = 130; xl.height = 130
   xl.anchor = f'F{row}'
   ws2.add_image(xl)
   ws2.row_dimensions[row].height = 145
   ```

### Step 4b：图片URL失效处理

下载404的常见原因和处理：
1. 淘宝图片URL中的数字ID是动态签名的，换一个搜索结果页的新URL即可
2. 下载请求必须带 `Referer: https://www.taobao.com/`（否则403）
3. CDN域名 `g-search1/g-search2/g-search3` 任一个都可，404可切换
4. 优先取 `_580x580q90.jpg` 后缀的URL
5. 批量失败后，重新到浏览器取新URL覆盖JSON中失败的条目再跑

### Step 5：构建Sheet3 竞品产品对比

**参数布局（B列起，A列参数名）：**
- R1: 商品链接 | R2: 品牌（黄色底） | R3: 产品名
- **R4: 图片（行高120，100×100）**
- R5-R28+: 价位/香型/成分/蜡基/燃烧时长/产地/定位/颜值评分/推荐指数/...
- **最后行: 推荐理由（行高80）**

**⚠️ 重要：确保R1列标题对齐**
| 列 | R1内容 | R2内容 |
|:--|:--|:--|
| A | 对比维度 | (空) |
| B~K | 搜索链接 | 品牌名 |

> R1的A列必须是"对比维度"，B~K列放搜索链接。不要给A列也塞链接。R2的B~K列放品牌名。

**⚠️ 数据对齐检查（常见错误：整列偏移）**

这是最容易出的bug：build代码中如果Excel的A列参数名是从第5行开始A5，但数据却从D5开始写（空着B、C），就会造成整列偏移。

**正确的写入方式：**
```python
# 品牌1 → B列(2), 品牌2 → C列(3), ... 品牌10 → K列(11)
for i, brand in enumerate(brands):
    col = 2 + i  # B=2, C=3, ..., K=11
    ws.cell(2, col).value = brand  # R2
    ws.cell(3, col).value = f'{brand} 产品名'  # R3
    ws.cell(5, col).value = price_range  # R5价位
```

**检查方法：** 读取第7行"面料支数"对应的B列应该是最前面品牌的数据，不是中间品牌的数据。

**修复偏移方法：**
```python
# D→B, E→C, ... M→K（左移2列）
for row in range(5, 28):
    for src_col in range(4, 14):  # D~M
        v = ws.cell(row, src_col).value
        if v:
            ws.cell(row, src_col).value = None
            ws.cell(row, src_col - 2).value = v  # B~K
```

## ⚠️ 核心规则：每一行产品必须独立获取图片和链接

这是整个工作中最重要的规则，也是最容易被忽略的坑：

### 规则
- **Sheet2里每一个产品行的图片和链接都必须独立获取**
- 即使是同一品牌的不同产品，也必须搜索不同的关键词，获取不同的淘宝商品页链接和不同的商品主图
- 绝对不能用品牌通用图塞给同一品牌的不同产品行
- 绝对不能复制同一个链接给同一品牌的多个产品

### 正确做法
为每一个产品行单独搜索不同的关键词，例如：

## 关键陷阱记录（避坑指南）

### 数据类
1. **Sheet3 B~K列数据必须对齐** — 最常见bug：品牌名在第2行B~K列，但参数数据从D列写入，导致整列偏移2列。检查办法：R7"面料支数"对应B列的值应该是**无印良品**的数据，不是山姆或宜家的。
2. **参数行号必须一一对应** — 另一个常见bug：第8行"纱织密度"的数据错填成了第7行"工艺"的数据，整块内容上移/下移1行。写入时必须显式指定row参数。
3. **品牌名和产品名对位** — Row2品牌名在B~K，Row3产品名也必须在同列的B~K，不能多出D~M列。
4. **同品牌不同产品图必须不同，链接也必须不同** — 必须检查文件大小确认内容不同！

### 图片类
5. **浏览器evaluate必须用原始targetId** — tabId会导致"tab not found"。获取targetId：`browser open`返回的`suggestedTargetId`，或`browser tabs`查看。
6. **淘宝CDN图片下载必须带Referer头** — 不加会返回403或404。
7. **URL失效处理** — 淘宝图片URL有动态签名，404了就重新搜索取新URL。CDN域名`g-search1/2/3`可互换试试。
8. **openpyxl XlImage必须用文件路径** — 传BytesIO会报"I/O operation on closed file"。
9. **PIL必须convert('RGB')** — 避免CMYK/RGBA图片导致openpyxl错误。

### Excel类
10. **保存前关Excel** — 否则PermissionError。被锁定时换文件名保存（`-修正版.xlsx`）。
11. **Sheet3 R4图片行高=120** — 100×100图片需要足够行高。
12. **Sheet3推荐理由行高=80** — 避免多行文字截断。
13. **Sheet3 R2品牌行必须黄色底色** — 重要视觉区分。

### 流程类
14. **CSV编码用utf-8-sig** — 避免BOM问题。
15. **browser navigate会更新当前tab** — 保持同一targetId，避免新建tab。
16. **subprocess模式的browser在获取到targetId线程安全** — 子任务和主任务不要同时操作同一个targetId。
17. **子任务完成后的图片嵌入** — 子任务只提取URL，下载和嵌入Excel在恢复主任务后统一处理。
